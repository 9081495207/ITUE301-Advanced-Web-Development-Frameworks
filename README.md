## 🛠️ Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

## 💻 Tech Stack
- **Framework**: React 19 + Vite
- **Routing**: React Router DOM v7
- **Styling**: Custom Vanilla CSS (CSS Modules / Custom Tokens)
- **Code Quality**: Oxlint
